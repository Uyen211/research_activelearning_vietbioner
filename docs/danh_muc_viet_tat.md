# DANH MỤC CÁC TỪ VIẾT TẮT

| Ký hiệu viết tắt | Thuật ngữ tiếng Anh gốc              | Diễn giải tiếng Việt                               |
| :--------------- | :----------------------------------- | :------------------------------------------------- |
| **NLP**          | Natural Language Processing          | Xử lý ngôn ngữ tự nhiên                            |
| **NER**          | Named Entity Recognition             | Nhận dạng thực thể có tên                          |
| **BioNER**       | Biomedical Named Entity Recognition  | Nhận dạng thực thể y sinh                          |
| **AL**           | Active Learning                      | Học chủ động                                       |
| **DES**          | Dictionary-based Entity Substitution | Thế thực thể dựa trên từ điển                      |
| **ETD**          | Entity Type Description              | Mô tả loại thực thể (bằng ngôn ngữ tự nhiên)       |
| **PLM**          | Pre-trained Language Model           | Mô hình ngôn ngữ tiền huấn luyện                   |
| **LoRA**         | Low-Rank Adaptation                  | Thích ứng hạng thấp                                |
| **CRF**          | Conditional Random Fields            | Trường ngẫu nhiên điều kiện                        |
| **SOTA**         | State-of-the-Art                     | Hiệu năng tốt nhất hiện tại                        |
| **AULC**         | Area Under the Learning Curve        | Diện tích dưới đường cong học tập                  |
| **SSR**          | Sentence Saving Ratio                | Tỷ lệ tiết kiệm mẫu câu                            |
| **ESR**          | Edit Saving Ratio                    | Tỷ lệ tiết kiệm thao tác hiệu chỉnh                |
| **OOV**          | Out-of-Vocabulary                    | Từ ngoài từ điển (từ vựng chưa thấy khi pre-train) |
| **POS**          | Part-of-Speech                       | Từ loại (nhãn cú pháp danh từ, động từ...)         |
| **NLL**          | Negative Log-Likelihood              | Hàm mất mát log-likelihood âm                      |
| **GPU**          | Graphics Processing Unit             | Bộ xử lý đồ họa                                    |
